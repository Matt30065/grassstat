# GrassSTATory Fresh Visual Proof v1.2.1

This is the clean player-card direction: **no kit studio, no shirt renderer, no avatars**.

## What is included
- Home screen
- Club Identity: Home primary/secondary + Away primary/secondary colours
- Create Player: name, number, position
- Premium player identity card with club name, number, position and autograph-style player name
- Compact squad card preview using the same identity system

## Important
This build is deliberately self-contained. CSS and JavaScript are inline in `index.html` to prevent old `style.css` or `app.js` files being mixed with the new proof.

## Clean repository recommendation
For this visual-proof repository, delete all old files first and upload only these files:
- `index.html`
- `bg-home-v121.jpg`
- `bg-stadium-v121.jpg`
- `club-badge-v121.svg`
- `README.md`

The UI displays `VISUAL PROOF · v1.2.1` in the bottom-right so you can immediately confirm the correct build is loaded.
